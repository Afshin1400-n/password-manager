# 🔐 Password Manager

یه مدیر رمز ساده و امن با Next.js و Zustand

## ✨ قابلیتها
- افزودن / ویرایش / حذف رمز
- دستهبندی (ایمیل، بانکی، شبکه اجتماعی و...)
- جستجو و فیلتر
- علاقهمندیها ⭐
- تم تاریک/روشن 🌙
- ذخیره خودکار در مرورگر

## 🛠 تکنولوژیها
- Next.js 14
- TypeScript
- Tailwind CSS
- Zustand (state management + persist)

## 🚀 اجرا
\`\`\`bash
npm install
npm run dev
\`\`\`

# 🌍 Countries Info

A modern, responsive web app to explore countries around the world.  
Search, filter by region, and view detailed stats — all in a clean, themeable UI.

## ✨ Features

- 🌐 **Browse Countries** — Powered by the [REST Countries API](https://restcountries.com/)
- 🔍 **Live Search** — Instant filtering by country name as you type
- 🗺️ **Region Filter** — Narrow down by Africa, Americas, Asia, Europe, Oceania
- 📊 **Smart Stats** — Total count, regions covered, and population summary
- 🌗 **Dark / Light Theme** — Toggle with persisted preference
- ⚡ **Fast & Optimized** — Zustand for state, `useMemo` for filtering
- 📱 **Fully Responsive** — Grid layout adapts from mobile to desktop
- 🎨 **Modern UI** — Glassmorphism search bar, smooth transitions

## 📦 Installation

### Prerequisites

- Node.js **18+**
- npm / yarn / pnpm

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/countries-info.git

# 2. Navigate into the project
cd countries-info

# 3. Install dependencies
npm install

# 4. Run the development server
npm run dev
